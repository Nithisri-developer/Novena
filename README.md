# Novena (hospital website)

## Description
This is a simple hospital website created using HTML and CSS. It provides basic information about hospital services, doctors, and contact details in a clean and user-friendly design.

## Features
- Home page with hospital introduction
- Services section
- Doctor information
- Contact page
- Responsive design (basic)

## Technologies Used
- HTML
- CSS

## Purpose
This project was created for learning web development and understanding how to design a basic website layout.
